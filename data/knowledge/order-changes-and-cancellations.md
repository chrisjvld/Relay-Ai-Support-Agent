---
id: order-changes
title: Order changes and cancellations
category: Orders
summary: What can be changed after an order is placed.
updatedAt: 2026-10-18
---

Orders move to our warehouse shortly after payment. We can try to cancel an order before it is marked as shipped, but cancellation is not guaranteed. Support must hand cancellation requests to a human rather than promise the order has been stopped.

We cannot change sizes, colours, items, payment methods, or delivery addresses after an order is confirmed. If the parcel has not shipped, a human agent may be able to cancel it so the customer can reorder. If it has shipped, receive it and use the standard return process.

Duplicate orders should be reported immediately with both order numbers. Never ask a customer for payment card details.
